Resumo para Hostinger: Projeto Streamlit com persistência em JSON. Suba repositório para GitHub e conecte ao deploy com Docker/Streamlit. Configure container Python 3.11, instale requirements.txt, defina comando `streamlit run app/streamlit_app.py --server.port 8501 --server.address 0.0.0.0`. Garanta volume para `data/`. Ative HTTPS e configure domínio apontando para o serviço. Opcional: usar GitHub Actions para build automático.
