Resumo para Hostinger: Projeto Streamlit com persistência em JSON. Suba repositório para GitHub e conecte ao deploy com Docker/Streamlit. Configure container Python 3.11, instale requirements.txt e execute `streamlit run app/streamlit_app.py --server.address 0.0.0.0 --server.port ${PORT:-8501}` (a plataforma define `PORT`; localmente use 8501). Garanta volume para `data/`. Ative HTTPS e configure domínio apontando para o serviço. Opcional: usar GitHub Actions para build automático.
