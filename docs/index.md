# Alvo Forecast

Bem-vindo ao hub público do projeto Alvo Forecast. Aqui você encontra o link para a aplicação interativa e instruções rápidas para o time de corretores.

## Acesse a aplicação

> Atualize o link abaixo após concluir o deploy (por exemplo, no Streamlit Community Cloud ou em um provedor de containers).

- [Abrir o Alvo Forecast](https://<seu-app-streamlit>)

## Como utilizar

1. Clique no link da aplicação para acessar o formulário e o dashboard.
2. Cadastre oportunidades, motivos de perda e objeções diretamente pela interface Streamlit.
3. Utilize a exportação em CSV para compartilhar os dados com outras ferramentas.
